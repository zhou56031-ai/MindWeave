# RAGNotebook 复刻路线

> 更新：2026-10-21。后端第 01–65 篇对应能力已接入；抽取审计、多模态 PDF、剩余 API、限流/日志/预热和最终契约测试已完成。前端直接复用参考项目源码。

## 1. 对齐目标

参考仓库为 RMA-MUN/RAGNotebook，目标提交为 `7445eb31dba2a9d07a1a5d4b7dd477d099a476f4`。当前本地源码还包含环境适配与本地自动登录定制，涉及它们时单独说明。

逐步对齐页面布局和交互、API 方法和路径、请求响应、数据模型、用户隔离、知识处理流程、图谱、检索与 Agent 行为。AI 生成文字不保证逐字相同，以功能、来源和状态变化验证。复用源码时保留原作者和 MIT 许可证信息。

技术主体沿用 React、FastAPI、MySQL、Redis、Neo4j、LangChain/LangGraph。模型按已选定的 DeepSeek 接入；嵌入模型另行配置，真实密钥只通过后端本地配置读取。

## 2. 当前起点

复刻项目位于用户指定的 RAGNotebook-rebuild，已有 Python 3.12.13 环境、现阶段后端依赖、requirements.txt、uv.lock 和独立 Git 仓库。本篇路线不重复编程基础课，也不要求先补做旧练习。

新版从[第 01 篇](chapters/01-backend-entry-and-health.md)创建正式后端代码。第 01–65 篇对应的笔记、知识库、PDF/Office、视觉批处理、Neo4j、Embedding、语义检索、GraphRAG、Web 兜底、多工具 Agent、checkpoint、Chunk 提及、双链、抽取审计和运维治理已接入。
