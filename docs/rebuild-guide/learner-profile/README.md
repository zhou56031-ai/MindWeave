## 怎样更新

1. 讲解前先查看知识地图和讲解策略。
2. 你提问、复述、展示代码、给出操作结果时，判断是否出现新的能力证据。
3. 有新证据才追加记录，并更新对应知识点；不会因为教程已生成而提高你的掌握等级。
4. 如果是知识类问题，同步整理到问答册，知识地图只保存判断和链接，不重复整篇答案。
5. 后续讲解根据更新后的状态调整。你也可以直接说明“这里我会了”或“这一步再讲细一点”，作为自评和偏好记录。

不需要先完成一整套考试才能继续学习。评估可以融入当前问题的一次复述或一个很小的操作。

## 与其他文档的区别

- **章节教程**：按什么顺序做，代码如何实现。
- **知识问答册**：你问了什么，答案与生动注释是什么。
- **本文件夹**：目前知道你理解到哪一层，接下来怎样讲更合适。
- **你自己的学习记录**：当天做到哪一步、遇到什么错误。
