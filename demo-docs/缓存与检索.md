# 缓存与检索速记

## 缓存击穿

热点 key 在过期瞬间失效，大量并发请求同时回源数据库，称为缓存击穿。
常见处理：

1. 互斥锁重建：只允许一个请求回源，其余等待或返回旧值；
2. 逻辑过期：value 里带过期时间，读命中但逻辑过期时返回旧值并异步续期。

选择依据：读延迟敏感用逻辑过期，实现简单优先用互斥锁。

## 缓存穿透与雪崩

- 穿透：查询根本不存在的数据，缓存不命中，请求全部落到数据库。可用布隆过滤器或空值缓存。
- 雪崩：大量 key 同时过期。可给过期时间加随机抖动，或做多级缓存。

## 混合检索

BM25 适合精确术语、错误码、函数名；向量适合同义改写与口语描述。
两者分数不可直接相加，常见做法是用 RRF 融合名次：

    score(d) = 1 / (k + rank_bm25(d)) + 1 / (k + rank_vector(d))

k 通常取 60。融合后仍需要重排，因为"字面相近"不等于"能回答这个问题"。
